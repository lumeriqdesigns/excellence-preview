# MeritScholars CBT PWA

## Setup keys
Edit **config.js** — see **CODES_TO_UPDATE.txt** and **SETUP_SUPABASE.txt**.

## Features
- Myschool-style layout, leaderboard, question bank (CBT/JAMB/WAEC)
- Student login & signup with **email verification** (Supabase)
- One-time Premium ₦2,000 (Paystack)
- Progress analytics, AI tutor, offline question bank

## Deploy
Upload this folder to GitHub → import on Vercel.
